# 视频素材替换说明

`video.html` 已支持“授权视频片段优先、图片电影化兜底”的结构。

请将你有使用权的视频片段放入：

```text
68haili_demo/assets/clips/
├── pingtan_sea.mp4        # 海岸/龙凤头/海浪
├── pingtan_aerial.mp4     # 航拍/猴研岛/海岛全景
└── blue_tears.mp4         # 蓝眼泪/夜景海浪
```

要求：
- 建议每段 5—8 秒，横屏 16:9，1080p 或以上；
- 视频会自动静音播放；
- 背景音乐仍使用 `assets/a_beautiful_life.mp3`（若存在），否则使用 `assets/bgm_fallback.mp3`；
- 如果某个 mp4 不存在，页面自动回退到当前高质量图片+运镜效果，不影响答辩。

版权提醒：不要直接下载或截取无授权的 YouTube/B站商业视频用于公开展示。若你确认拥有授权，可按以上文件名放入本目录，系统会自动使用。
