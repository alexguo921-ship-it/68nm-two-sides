一、项目初心 · 我为什么做这件事

我是潮汕人，从小听着闽南语—潮汕话—福佬话之间无法精确切割的"语言连续体"长大；后来成为复旦大学外国语言文学学院的翻译硕士。

当我站在猴研岛的礁石上，听到福州话与台湾闽南语在同一张桌上对话——潮汕人对"南方语言连续体"的本能敏感被瞬间唤醒。我意识到，平潭离台湾只有 68 海里，但我们一直在拍它的"风景"，没有人翻译它的"声音"。

这套方案不是普通的"看海三日游"，而是把翻译硕士的文本敏感、潮汕人的方言耳朵、近 200 城产品视野整合成一个能落地的文旅产品——把"听不懂"变成"听透"，把"两岸距离"变成"两面体验"。

— GUO JIA · 复旦大学外国语言文学学院 · 翻译硕士 MTI · 25210120088

五、操作要点 · 一图速查

翻页 · 答辩 PPT

键盘 ← → / 空格 切换；底部右下角支持鼠标点击；进度条显示当前进度。

语言切换 · 官网

页面右上角 CN / EN / TC 三键，所有正文同步切换，刷新后记忆。

全屏播放 · 介绍片

点击播放后，可按浏览器 F11 进入全屏；支持背景音乐与字幕同步。

跨页跳转

所有页面右上角带 ← 网站 / DECK 按钮，可随时返回主入口。

沉浸式动效

首页全屏海浪粒子、方言区音频波形、特殊汉字（厝/鼎/箸/泪/听）悬停发光，建议鼠标轻悬感受细节。

背景音乐

右下角 音符按钮可启停 BGM；首次需用户点击页面任意位置自动播放（浏览器策略）。

六、作者自评 · 优缺点坦言

以下为本人对作品的自我审视，希望能为评委老师提供更立体的判断维度。

✓ 自认优势

  • 叙事独特性：把"翻译硕士+潮汕方言耳"嫁接到文旅产品，市场上没有同款角度
  • 商业闭环完整：3 档套餐 + ¥99 PASS 卡 + 蓝眼泪盲盒保险，每一笔风险都有变现接口
  • AI 不流于噱头：方言翻译器 / VLM 石厝扫描 / 运营大屏，三个原型都给出可落地的接口设想
  • 视觉一体化：官网 / PPT / 介绍片 / 小程序使用同一套设计语言（Noto Serif SC + 鹅黄主色 + 海岛色板）
  • 可即时验证：所有材料已同时部署到 Vercel / Cloudflare Pages / GitHub Pages 三个平台，评委可手机直接打开查看，不依赖本地软件

△ 自认不足

  • 蓝眼泪保险机制需要与持牌保险公司联合开发，目前停留在产品形态描述阶段
  • AI 原型为前端模拟：方言翻译/VLM 扫描尚未接入真实模型，量产需要算法团队介入
  • 实地田野不够厚：基于一次平潭考察 + 潮汕语感经验，尚未做大样本游客访谈验证客单价
  • 合作机构未实质对接：B 端报价表为类比定价，签订意向书需运营团队推进
  • 文创衍生品成本：黑胶/压仓石文镇定价 ¥58—168，初期 SKU 库存压力需联合本地工坊摊薄
温馨提示：建议使用 Chrome、Edge、Safari 最新版本浏览器打开以获得最佳体验。线上版本会持续迭代，本地资料包为评审定版快照——若发现两者细节有差异，以线上版为准。
